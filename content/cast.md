# Cast

One block per speaking character. Every new character costs:
- a full set of cutout figure parts (head, eyes, mouth shapes, body, arms);
- a voice.

Aim for 3–5 recurring characters per faction, plus a few one-off speakers.

Copy this block per character:

```
## <NAME AS IT APPEARS IN FOUNTAIN, e.g. COMMANDER VOSS>
- Faction:
- Role in the story (one line):
- Appears in missions:
- Look (for the figure parts): age, build, face, uniform, one distinctive feature
- Poses/emotions needed: e.g. neutral, grim, angry, laughing, pointing at map
- Voice: pitch (low/mid/high), speed, accent (if any), one adjective (e.g. "dry")
- Speech habit or catchphrase (keep it original):
- Notes:
```
